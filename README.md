# Industry and Device-Related Payments to Advanced Heart Failure and Transplant Cardiology Specialists, 2018--2024

These files, in combination with freely and publicly available Open Payments and National Plan and Provider Enumeration System (NPPES) data, can be used to recreate the analyses presented in our study of industry and device-related payments to advanced heart failure and transplant cardiology (AHFTC) specialists in the United States from 2018--2024.

## A Brief Overview of the Files & Their Structure

1.  The **Data Construction Scripts** contain the R code used to
    identify the AHFTC specialist cohort, process annual Open Payments
    data, classify device-related payments, consolidate manufacturers
    and products, and construct the final analytic datasets.

2.  The **Analysis Scripts** contain the R code used to generate the
    tables, figures, and statistical analyses presented in the
    manuscript.

3.  **DATASET_FINAL.RData** contains the finalized R data objects used
    in the manuscript analyses. This file is provided so that users
    interested primarily in examining the analytic data or reproducing
    the analyses can do so without rerunning the complete
    data-construction pipeline.

## Reproducing the Analysis

There are two options for reproducing the study:

### Option 1: Recreate the Analytic Datasets

Users wishing to reproduce the complete data-processing workflow can
download the publicly available source data described below and run the
Data Construction Scripts in sequence. These scripts generate the final
analytic datasets used in the study, with two exceptions:

i) manual review of final NPI list, including (a) the addition of a small number 
of NPIs following review of relevant guidelines, scientific statements, and 
societal consensus statements, (b) removal of a small number of NPIs based on 
provider characteristics (e.g., APP or trainee), and re-classification of a 
small number of NPIs as dual-subspeaiclists

ii) regular updates to NPPES data. Our team downloaded the version 12/2025

For these reasons, Option 2 allows users to download pre-generated datasets 
for analysis

Once the datasets have been constructed or downloaded, the Analysis Scripts 
can be run to reproduce the manuscript tables, figures, and analyses.

### Option 2: Begin With the Final Analytic Data

Users interested primarily in examining the analytic data or reproducing
the manuscript analyses can instead download **DATASET_FINAL.RData** and
proceed directly to the Analysis Scripts.

The file can be loaded into R using:

``` r
load("DATASET_FINAL.RData")
```

This loads the finalized data objects used by the analysis scripts,
including the physician-level, physician-manufacturer,
manufacturer-level, and device-level analytic datasets.

## Publicly Available Source Data

Recreating the datasets from the beginning requires the following
publicly available CMS data:

1.  **Open Payments General Payments Data (2018--2024)**\
    Annual general payment files are available from the CMS Open
    Payments Program:\
    https://openpaymentsdata.cms.gov/datasets

2.  **Open Payments Covered Recipient Supplement File**\
    This file is used to link Open Payments physician identifiers with
    National Provider Identifiers (NPIs) and is available through CMS
    Open Payments.

3.  **NPPES/NPI Data**\
    NPPES data are used to identify physicians registered under the
    AHFTC taxonomy and obtain relevant physician characteristics:\
    https://download.cms.gov/nppes/NPI_Files.html

Users choosing **Option 2** do not need to download or process these
source files.

## Final Analytic Data

`DATASET_FINAL.RData` contains the principal data objects generated by
the Data Construction Scripts and used in the manuscript analyses,
including:

-   `ahftc_npis` --- AHFTC physician cohort and physician
    characteristics
-   `ahftc_summary_nature` --- physician-level payment and analytic
    dataset
-   `per_phys_all` --- physician-manufacturer-year payment data used to
    identify significant financial relationships
-   `ever_over` --- physician-manufacturer relationships meeting the
    prespecified payment threshold
-   `master_company` --- manufacturer-level payment summary
-   `master_company_device_consolidated` --- device-level payment
    summary
-   `top50_devices` --- leading devices by cumulative payment value

The provided data are **processed analytic datasets rather than the
original raw CMS data**. Manufacturer consolidation, device
classification, identification of device-related payments, and
construction of derived variables have already been performed.

## Software

Analyses were performed in R. Required packages are specified within the
